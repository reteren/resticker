# Инвентаризация: window_picker.rs под Dark Liquid Glass

Поверхность **H** (спецификация §8, файлы `window_picker.rs` + `window_pick_list.rs`).
Этот отчёт — только про `crates/resticker/src/window_picker.rs` (1833 строки).
`window_pick_list.rs` инвентаризируется отдельно.

Модуль состоит из двух частей:
- **Логика** (строки 1–296): предикаты, группировка, переключатели — к дизайну
  отношения не имеет, не переписывается.
- **Билдер панели** (строки 298–703): константы геометрии, `build_picker_panel`,
  `RowLabel`, вспомогательные функции. Вся перекраска — здесь.
- **Тесты** (строки 705–1833).

**Ключевой вывод.** Панель выбора окон — единственная на поверхности H, которая
**не использует `WidgetStyle::Settings` и `theme::settings` вообще** (ни одной
строки; проверено grep'ом по всему крейту). Она собрана в дефолтном стиле
`WidgetStyle::Overlay` — «тёмно-серая схема» `theme::PANEL_BG`, которая по §1
спецификации тоже выводится из употребления. Механическое удаление
`WidgetStyle::Settings`/`theme::settings` этот файл **не сломает** — его ломает
замена палитры `theme::PANEL_BG`/`BUTTON_BG`/`FIELD_*`/`SLIDER_*` на токены §2.

## 3. Старые рамки/бевель/объём (settings_bevel, settings_frame,
   settings_frame_radius, accent_outline)

Прямых вызовов **в этом файле нет**. Виджеты, которые он инстанцирует, рисуют
объём только в ветке `WidgetStyle::Settings`, а здесь активна ветка `Overlay` —
плоские Fill'ы. Поэтому для этой панели «старый стиль» — это плоские

## 6. Риски и странности

1. **Синий акцент прокрался в панель косвенно, §2.4 нарушен уже сейчас:**
   галочка чекбокса — `SLIDER_FILL #4F9CFF` (widgets.rs:2342), ручка скролла —
   он же @ 0.9 (widgets.rs:1300). При переписывании виджетов в дорожке A это
   уйдёт само, но в этом модуле **нельзя** снова использовать `SLIDER_FILL` для
   «белого» — токены менять на `TEXT`/`TEXT_DIM`.
2. **Механическая замена не сработает для чекбоксов в режиме disabled:**
   `Checkbox::draw` глушит всё `opacity: 0.45` (widgets.rs:2235). В §2 токена
   «выключенный контрол» нет (`TEXT_FAINT` — для текста, не для тела). Решение:
   рисовать disabled-чекбоксы окна как `glass_control` в покое с пониженной
   прозрачностью (или `TEXT_FAINT`-галочку на `CTRL_BG`) — выбрать и зафиксировать.
3. **Панель сегодня без скругления** (`Panel::new` без `with_corner_radius`,
   стр. 391): переход на `RADIUS_WINDOW`=18 меняет силуэт панели — проверить, что
   в `overlay_manager.rs` (позиционирование панели, тултипы) не зашито 0-радиусных
   допущений. Высота панели вырастет: 2·(14−6)=+16 за счёт пада и 20 за счёт
   `BUTTON_SIZE` 28→30 — панель станет выше на ~36 DIP при выборе `PAD_PANEL`.
4. **Плейсхолдер иконки — `Primitive::Fill` с цветом `BUTTON_BG`** (стр. 663):
   при замене на стеклянный мини-контрол тесты-счётчики (`icon_slot_count`,
   §5) и фильтры в `overlay_manager` (если он считает Fill'ы панели) разъедутся.
   Возможное решение без новых примитивов — оставить `Fill` с токеном `CTRL_BG`.
5. **Магическое `8.0` в `btn_w`** (стр. 423) — прямое нарушение §9.1; при
   переводе на `PAD_CTRL_X`=12 убрать.
6. **`PICKER_HEADER_H`=40 vs `BUTTON_SIZE`=30:** после роста кнопки до 30 шапка
   (40) останется с запасом 10; строки 406 (`header_y`) пересчитаются сами, но
   зазор 40−30=10 — непонятный «висячий» отступ: предложить `PICKER_HEADER_H =
   BUTTON_SIZE + GAP_ROW` или просто выровнять по паду.
7. **Тик-требование §5 вступает в силу только с появлением `UiTick` (дорожка
   J):** пока его нет, анимации на этой панели будут замирать при остановке
   курсора — не считать это багом модуля.
8. **`text_rect`/`truncate_to_width` завязаны на `text_size`** (стр. 422, 452–453,
   552–564): смена гарнитуры на Commissioner (12.5/600, §6) меняет ширины —
   `PICKER_WIDTH`=320 и пороги обрезки нужно проверить визуально; тесты §5
   пересчитать.
9. **Скроллбар не имеет токена в §3/§2:** ни размера (3.0), ни цвета
   (`SLIDER_TRACK`@0.5 / `SLIDER_FILL`@0.9). Пока дорожка A не даст токена,
   для перехода использовать `TEXT_DIM`@~0.5–0.9 с шириной ~`HAIRLINE`·3 или
   оставить 3.0 — зафиксировать выбор.
10. **`CHECKBOX_SIZE`=16 не покрывается §3:** радиус `RADIUS_CTRL`=10 и
    `BUTTON_SIZE`=30 есть, размера чекбокса нет. Колонки на строках 441–444
    считаются от него; при смене размера пересчитать `PICKER_WINDOW_INDENT`
    (24) и `process_label_left`.
