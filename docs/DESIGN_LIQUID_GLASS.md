# Dark Liquid Glass — дизайн-система resticker

Статус: **действующая спецификация**. Всё, что рисует resticker — оверлейные
панели, окно настроек, меню трея, тулбары, бейджи, диалоги — приводится к
этому документу. Старые языки оформления (Half-Life 2 / Source VGUI в
`ui/styles.css` и `theme::settings`, тёмно-серая схема `theme::PANEL_BG`)
**выводятся из употребления целиком**, а не сосуществуют с новым.

Референс материала — `github.com/reteren/Renarrator` (`src/styles.css`,
«Liquid Glass design system»). Оттуда берётся МЕТОД: слоистая полупрозрачность,
зеркальный блик, однопиксельные кромки, монохром без цветного акцента. Отличие
resticker: **база чёрная, а не белая**. Renarrator кладёт белую плёнку на
акрил; мы кладём чёрное стекло и оживляем его только светом.

---

## 1. Что должно чувствоваться

Три ощущения, по которым проверяется любая правка:

1. **Глубина без цвета.** Панель — не серый прямоугольник, а плита чёрного
   стекла: сверху она ловит свет, снизу тонет. Единственный «цвет» интерфейса —
   белый свет разной силы.
2. **Свет живёт на кромках и на тексте.** Текст слегка светится; рамки — не
   линии, а блик на грани; наведение зажигает мягкое гало.
3. **Контрол отвечает телом.** Под курсором кнопка **продавливается** внутрь
   (уменьшается и темнеет в центре), одновременно наливаясь белым по краю.
   Не «подсвечивается» — именно проминается.

### 2.4 Единственный цвет во всём интерфейсе

`DANGER = #D0463C`. Только тонкие предупреждения (кольцо не влезающей
раскладки, пульс открепления окна). Заливать им площади запрещено.
**Синего акцента `#4F9CFF` и бирюзового `#3C9898` больше нет нигде.**
Всё, что было «акцентом», становится белым разной силы.

## 3. Геометрия

| Величина | DIP | Где |
|---|---|---|
| `RADIUS_WINDOW` | 18 | корпус большой панели, окно настроек |
| `RADIUS_CARD` | 14 | карточка внутри панели |
| `RADIUS_CTRL` | 10 | кнопка, поле, чекбокс |
| `RADIUS_TIGHT` | 7 | мелкая иконка-кнопка, бейдж |
| `HAIRLINE` | 1.0 | кромка и обводка |
| `PAD_PANEL` | 14 | внутренний отступ корпуса |
| `PAD_CTRL_X` | 12 | горизонтальный отступ подписи в кнопке |
| `GAP_ROW` | 10 | между строками |
| `BUTTON_SIZE` | 30 | сторона квадратной кнопки тулбара (было 28) |

Тулбар стикера остаётся с малым радиусом (`RADIUS_TIGHT`) — он узкий, большое
скругление съедает крайние кнопки. Это единственное исключение.

## 4. Материал: из каких слоёв собрано стекло

Снизу вверх, для одного скруглённого прямоугольника:

1. **Тело** — `GLASS_INK` (или `CTRL_BG*` для контрола), сплошная заливка по
   скруглённому контуру со сглаженным краем.
2. **Вертикальный градиент** — `GLASS_SHEEN_TOP` → `GLASS_SHEEN_BOTTOM` сверху
   вниз. Он и делает плиту «стеклом», а не краской.
3. **Зеркальный блик** — радиальное пятно `GLASS_SPECULAR` в левом верхнем
   углу, ширина ≈ 65 % корпуса, высота ≈ 45 %, гаснет к нулю. У Renarrator оно
   дополнительно искажено SVG-турбулентностью (`filter: url(#liquid-soft)`) —
   в оверлее эквивалент даёт лёгкое синусоидальное искривление границы пятна,
   амплитуда 3–4 % высоты. Это и есть «жидкость» в liquid glass.
4. **Внутренние кромки** — `RIM_TOP` сверху, `RIM_SIDE` по бокам,
   `RIM_BOTTOM` снизу, толщина `HAIRLINE`, повторяют скругление.
5. **Внешняя обводка** — `STROKE` по контуру.
6. **Гало** (только под курсором/у первичной кнопки) — мягкое белое свечение
   наружу, `HOVER_GLOW`.

Порядок обязателен: блик поверх градиента, кромки поверх блика, гало снаружи.

Утопленная поверхность (`Sunken`) переворачивает свет: тёмная кромка сверху,
`RIM_BOTTOM` снизу, градиента нет.

## 5. Движение

Кривая — `ease-out` Renarrator: `cubic-bezier(0.22, 1, 0.36, 1)`.
В Rust — хелпер в `theme`, а не магические числа по месту.

| Переход | Длительность |
|---|---|
| наведение / уход курсора | **160 мс** |
| нажатие | **110 мс** |
| появление панели | **240 мс** (`opacity 0→1`, сдвиг `+8→0` DIP, `scale 0.985→1`) |
| появление меню трея | **150 мс**, origin — угол у курсора |
| появление карточки в списке | **300 мс**, каскад по `+40 мс` на элемент, максимум 6 шагов |

### Как именно «продавливается» кнопка

`t` — прогресс наведения 0→1:

- `scale`: `1.0 → 0.972` (прямоугольник ужимается вокруг центра);
- фон: `CTRL_BG → CTRL_BG_HOVER`;
- `RIM_TOP` гаснет `0.34 → 0.14`, `RIM_BOTTOM` разгорается `0.055 → 0.22`
  (свет переезжает вниз — читается как вдавленность);
- наружу выходит `HOVER_GLOW` с силой `t`.

Зажатие добавляет `scale → 0.955` и фон `CTRL_BG_ACTIVE`.

**Важно про перерисовку.** `redraw()` в координаторе событийный: если курсор
замер над кнопкой, событий больше нет и анимация замрёт на середине. Поэтому
пока хоть один виджет живой панели анимируется, координатор обязан
планировать тик ~60 Гц (тем же механизмом, что `OverlayMessage::AnimationTick`
для спрайтов, отдельным сообщением `UiTick`) и прекращать его, когда все `t`
дошли до 0 или 1. Без этого «плавно» не будет — будет рывок.

## 6. Типографика

**Основная гарнитура — Commissioner** (`OFL`, вендорена в
`crates/rst-render/assets/Commissioner-Medium.ttf` и `-SemiBold.ttf`,
в вебвью — `crates/resticker/ui/fonts/commissioner-{latin,cyrillic}-{400,500,700,800}.woff2`).

**Bitcount Grid Single не может набирать русский**: в шрифте 0 из 64
кириллических букв (замерено `fontTools` 2026-08-29). Поэтому он используется
**только как акцент на латинице и цифрах**: номер группы в ленте, словесный
знак `RESTICKER`, счётчики. Весь остальной текст — Commissioner.

| Роль | Гарнитура | Кегль DIP | Вес | Цвет |
|---|---|---|---|---|
| основной текст UI | Commissioner | 12.0 | 500 | `TEXT` |
| подпись кнопки | Commissioner | 12.0 | 500 | `TEXT` |
| заголовок секции | Commissioner | 10 | 800, разрядка `0.16em`, CAPS | `TEXT_FAINT` |
| заголовок окна/панели | Commissioner | 16 | 800 | `TEXT` |
| второстепенное | Commissioner | 12 | 500 | `TEXT_DIM` |
| номер группы, счётчик | Bitcount Grid Single | 15 | 400 | `TEXT` |

**Замеры 2026-08-29, ставшие фактом (растеризатор оверлея уже переведён):**
кегль оверлея — **12.0 DIP, не 12.5**: у Commissioner подъём 1.017 em против
0.928 em у Roboto, на одном номинальном кегле он и так рисует крупнее, а 12.5
дало бы только лишний DIP высоты. `LINE_HEIGHT` вырос **15 → 16 DIP**: с
запасом над базовой линией строка Commissioner требует 15.18 DIP, и в 15 у
«p»/«y» срезало хвосты. Кто верстает по `text::LINE_HEIGHT` — получит новое
значение сам; кто зашил 15 числом — обязан перейти на константу. Цифры
выровнены в общий слот (синтетический `tabular-nums`): в самой гарнитуре они
пропорциональные, и счётчики/таймеры дёргались бы по ширине.

**Свечение текста** запекается в растр в `rst_render::text::rasterize`:
глифы рисуются поверх собственной размытой белой копии (`TEXT_GLOW`).
Растр расширяется на `GLOW_PAD` DIP с каждой стороны, `text_size` **остаётся
прежним** (это по-прежнему коробка вёрстки), а расширение компенсирует
единственное место сшивки — `rst_render::ui_textures`, которое рисует растр в
прямоугольник, раздутый на `GLOW_PAD`. Ни один вызывающий модуль про гало не
знает и своих отступов не меняет.

## 7. API, на который опираются все панели

Появляется в `rst-render` (дорожка A, делает координатор). До его готовности
панели не переписываются.

```rust
// widgets.rs
pub enum Surface { Panel, Card, Modal, Control, ControlHover, ControlActive,
                   ControlPrimary, ControlOn, Sunken, Danger }

pub enum Primitive {
    /* … существующие … */
    /// Скруглённый прямоугольник стекла со всеми слоями §4.
    Glass { rect: Box2D, radius: f64, surface: Surface, glow: f64, opacity: f64 },
}

/// Корпус панели (§4, Surface::Panel) — замена settings_frame_radius.
pub fn glass_panel(out: &mut Vec<Primitive>, rect: Box2D, radius: f64, opacity: f64);
/// Контрол с учётом фазы наведения/нажатия: сам ужимает rect и выбирает Surface.
pub fn glass_control(out: &mut Vec<Primitive>, rect: Box2D, radius: f64,
                     hover_t: f64, press_t: f64, primary: bool, opacity: f64);
```

Растр стекла генерируется процедурно (как уже сделано для скруглённых углов в
`settings_corner_rgba`) и кэшируется в `ui_textures` по ключу
`(surface, ширина, высота, радиус, ступень гало, масштаб DPI)`. Размеры панелей
стабильны между кадрами, поэтому кэш попадает почти всегда; LRU на 64 записи.

`WidgetStyle::Settings` **удаляется**: двух языков больше нет, есть один.
Модуль `theme::settings` удаляется вместе с ним.

Каждый виджет получает поля фазы и метод продвижения времени:

```rust
pub trait Widget {
    /* … */
    /// Продвинуть анимации на dt мс. `true` — что-то ещё движется.
    fn animate(&mut self, dt_ms: f64) -> bool { false }
}
impl Panel { pub fn animate(&mut self, dt_ms: f64) -> bool; }
```

## 9. Правила, нарушение которых ломает сборку или вид

1. **Никаких магических чисел.** Любой цвет, радиус, отступ, длительность —
   только через `theme::*`. Литерал `[u8; 3]` в модуле панели — ошибка.
2. **`edition = 2024`, но `rust-version = 1.85`: let-chains запрещены.**
   Вместо `if let A = x && let B = y` — вложенные `if let`.
3. Комментарии и доккоменты — по-русски, как во всём проекте; объясняют
   ПОЧЕМУ, а не что.
4. Каждый модуль после правки: `cargo fmt`, `cargo clippy -- -D warnings`,
   `cargo test -p <крейт>` — зелёные. Тесты геометрии, которые ломаются от
   смены размеров, чинить осмысленно, а не удалять.
5. Сборка требует окружения: `FFMPEG_DIR=C:/dev/ffmpeg-lgpl-shared-old`,
   `MINGW_RUNTIME_DIR=C:/msys64/mingw64/bin`. Перед `cargo build --release`
   процесс `resticker.exe` должен быть остановлен — иначе «файл занят».
6. **Не трогать и не сворачивать реальные окна пользователя.** Для замеров —
   свой одноразовый блокнот.
7. Ни один агент не коммитит. Коммит — решение пользователя.
